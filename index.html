02 / Case Studies
01 RAG · Agentic AI

Document-grounded RAG chatbot, deployed on AWS with Claude 4.5 Sonnet

Problem

Users needed accurate answers drawn strictly from their own uploaded documents — not generic model knowledge — with responses that could be trusted for decision-making.

Approach

Built an ingestion pipeline that chunks and embeds documents uploaded to Amazon S3, indexes them in a vector store, and retrieves relevant context per query. Claude 4.5 Sonnet generates the final answer strictly grounded in retrieved passages, reducing hallucination and keeping responses traceable to source text.

Deployment

Containerized with Docker and deployed on AWS — S3 for document storage, compute for the retrieval/generation service — giving the system a scalable, cloud-native footprint from day one.

Claude 4.5 Sonnet AWS S3 AWS Compute Vector Search Docker
02 Reinforcement Learning

DRL-based document matching engine on AWS

Problem

Static, rule-based matching couldn't keep up with varied document formats and evolving request patterns — match quality degraded as content diversity grew.

Approach

Designed a Deep Reinforcement Learning agent that learns a matching policy over time: documents land in Amazon S3, get featurized, and the agent scores candidate matches against incoming requests, using a reward signal from match outcomes to keep improving.

Deployment

Packaged with Docker and deployed on AWS for real-time inference, so match quality keeps compounding in production rather than needing manual rule updates.

Deep RL AWS S3 AWS Compute Docker
